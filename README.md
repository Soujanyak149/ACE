# 🧠 ACE - Adaptive Cognitive Education

A comprehensive learning platform designed to enhance cognitive abilities through interactive modules, real-time multiplayer battles, and AI-powered progress tracking.

## 🎯 Features

### ✅ Completed Modules

1. **🔢 Mathematics Practice**
   - Multiple difficulty levels (Beginner to Expert)
   - Various game modes (Practice, Timed, Survival, Boss)
   - Adaptive learning with performance tracking
   - Real-time feedback and scoring system

2. **📚 Language Learning**
   - Categories: Synonyms, Antonyms, Definitions, Word Pairs
   - Smart hints and contextual explanations
   - Combo system for consecutive correct answers
   - Vocabulary growth tracking

3. **🧩 Puzzle Solver**
   - Logic puzzles, number sequences, pattern recognition, riddles
   - Multiple difficulty levels
   - Smart hints system
   - Progress tracking and improvement analytics

4. **⚔️ Quiz Battle**
   - Real-time multiplayer quiz battles
   - Multiple battle modes (Quick Match, Ranked, Private Room, Tournament)
   - Live chat during battles
   - Global leaderboard and ranking system

5. **💻 Programming Learning Hub** ⭐ EXPANDED: Now includes Python & DSA!
   - **18 Comprehensive Topics** across multiple languages and concepts
   - **JavaScript Fundamentals** (9 topics):
     - Variables, Data Types, Conditionals, Loops, Functions
     - Arrays, Objects, Strings, DOM Manipulation
   - **Python Basics** (3 topics):
     - Python Introduction, Lists & Tuples, Dictionaries
   - **Data Structures & Algorithms** (6 topics):
     - Linked Lists, Stacks & Queues, Trees
     - Sorting Algorithms, Searching Algorithms, Recursion
   - Real-world code examples with detailed explanations
   - Interactive quizzes after each lesson
   - Syntax-highlighted code demonstrations
   - Suitable for beginners to interview preparation

6. **📊 Progress Tracker** ⭐ NEW: Real-Time Tracking System
   - **Real-time performance analytics** - Tracks actual game data from all modules
   - **Persistent data storage** using localStorage (no backend required)
   - **Comprehensive statistics** per module:
     - Questions attempted and correct answers
     - Total score and high scores
     - Time spent and streaks
     - Category-specific breakdowns
   - **8 Achievement System** with progress tracking:
     - Math Master, Word Wizard, Puzzle Pro, Battle Champion
     - Streak Master, Perfectionist, Speed Demon, Code Ninja
   - **User level system** calculated from total score
   - **Overall accuracy** tracking across all modules
   - **Interactive dashboard** with test data generation
   - **Visual progress indicators** with charts and graphs

## 🎯 Real-Time Progress Tracking System

### Features:
- **Persistent Storage**: All progress saved to browser localStorage
- **Module Integration**: Each game module automatically saves performance data
- **Real-Time Updates**: Dashboard reflects latest game statistics
- **Achievement System**: 8 unique achievements with progress tracking
- **Cross-Session**: Progress persists across browser sessions
- **Privacy-Focused**: All data stored locally on user's device

### What Gets Tracked:
**📈 Global Stats:**
- Total score across all modules
- User level (increases with score)
- Overall accuracy percentage
- Total study time

**📊 Per Module:**
- Questions/puzzles attempted and solved
- Accuracy rates and scores
- Time spent per module
- Streaks and high scores
- Category/difficulty breakdowns

6. **Perfectionist** - Achieve 100% accuracy in 10+ question session
7. **Speed Demon** - Answer 10 questions in under 5 seconds each
8. **Code Ninja** - Complete all 9 programming topics

### How to Use:

## 🚀 Quick Start

### Prerequisites
- Python 3.8 or higher
- Modern web browser with JavaScript enabled

### Installation

1. **Clone or download the project**
   ```bash
   # If using git
   git clone <repository-url>
   cd ACE
   ```

2. **Install Python dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Start the backend server**
   ```bash
   python start_backend.py
   ```

4. **Open the frontend**
   - Open `index.html` in your web browser
   - Or serve it using a local web server for better performance

## 🎮 How to Use

### Frontend Navigation
1. **Main Dashboard**: Access all learning modules from the main page
2. **Individual Modules**: Each module has its own dedicated page with full functionality
3. **Progress Tracking**: View detailed analytics and AI recommendations
4. **Quiz Battles**: Join real-time multiplayer competitions

### Backend API
The backend provides RESTful APIs for:
- User authentication (`/api/auth/`)
- Progress tracking (`/api/progress/`)
- Question generation (`/api/language/`, `/api/puzzle/`)
- Leaderboards (`/api/leaderboard/`)
- Real-time multiplayer (WebSocket via SocketIO)

## 🔧 Configuration

### Environment Variables
- `ACE_SECRET`: Secret key for Flask sessions (default: 'dev_secret_key_change_in_production')
- `ACE_DB_URI`: Database connection string (default: 'sqlite:///ace.db')
- `PORT`: Server port (default: 5000)

### Database
- Uses SQLite by default for easy setup
- Automatically creates tables on first run
- Stores user progress, achievements, and leaderboard data
