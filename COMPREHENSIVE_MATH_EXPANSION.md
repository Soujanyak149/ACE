## 🎮 **Sample Questions You'll See:**

### **🔥 Word Problems:**
```
Question: "Sarah buys a book for $15 and a notebook for $8. How much does she spend in total?"
Answer: 23
Hint: "Add the prices: $15 + $8 = $23"

Question: "A car travels at 60 mph for 3 hours. How far does it go?"
Answer: 180
Hint: "Distance = Speed × Time = 60 × 3 = 180 miles"
```

### **🔥 Trigonometry:**
```
Question: "What is sin(30°)? (Round to 3 decimal places)"
Answer: 0.5
Hint: "sin(30°) = 0.5 (special angle)"

Question: "Right triangle: sides a=3, b=4. Find hypotenuse c (round to 2 decimals)"
Answer: 5.00
Hint: "Pythagorean theorem: c² = a² + b² = 3² + 4² = 25, so c = 5.00"
```

### **🔥 Exponents & Roots:**
```
Question: "What is 3⁴?"
Answer: 81
Hint: "3⁴ = 3 × 3 × 3 × 3 = 81"

Question: "What is √64?"
Answer: 8
Hint: "√64 = 8 because 8² = 64"

Question: "Simplify: 2³ × 2²"
Answer: 2⁵
Hint: "When multiplying same bases, add exponents: 2³ × 2² = 2³⁺² = 2⁵"
```

### **🔥 Statistics & Data:**
```
Question: "Find the mean (average) of: 4, 8, 12, 16"
Answer: 10
Hint: "Add all numbers: 4 + 8 + 12 + 16 = 40, then divide by 4: 40÷4 = 10"

Question: "Find the median of: 3, 7, 12, 15, 21"
Answer: 12
Hint: "Sort the numbers: 3, 7, 12, 15, 21. The middle value is 12"
```

### **🔥 Pre-Calculus:**
```
Question: "If f(x) = 4x + 7, find f(3)"
Answer: 19
Hint: "Substitute x = 3: f(3) = 4(3) + 7 = 12 + 7 = 19"

Question: "Find the slope between points (1, 2) and (4, 8)"
Answer: 2
Hint: "Slope = (y₂ - y₁)/(x₂ - x₁) = (8 - 2)/(4 - 1) = 6/3 = 2"
```
