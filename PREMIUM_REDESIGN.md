## 🎨 Design Principles Applied

### **1. Spacing & Rhythm**
```css
Extra Small: 0.5rem (8px)
Small:       1rem (16px)
Medium:      1.5rem (24px)
Large:       2rem (32px)
Extra Large: 3rem (48px)
2X Large:    4rem (64px)
```

### **2. Border Radius**
```css
Small:  8px  - Inputs, tags
Medium: 12px - Buttons, cards
Large:  16px - Larger cards
XL:     24px - Modals, sections
Full:   9999px - Pills, circles
```

### **3. Shadows**
```css
Small:  Subtle depth
Medium: Cards at rest
Large:  Interactive elements
XL:     Modals, overlays
Glow:   Primary actions
```

### **4. Transitions**
```css
Fast: 150ms - Micro-interactions
Base: 300ms - Default transitions
Slow: 500ms - Large animations
```

## 🎓 Design Decisions

### **Why Poppins?**
- **Modern:** Contemporary geometric sans-serif
- **Professional:** Used by Google, Spotify, Airbnb
- **Readable:** Clear at all sizes
- **Versatile:** Works for headings and UI

### **Why Indigo Primary?**
- **Trust:** Associated with reliability
- **Intelligence:** Perfect for education
- **Modern:** Trending in 2024-2025 design
- **Versatile:** Works in light and dark modes

### **Why 8rem Title?**
- **Impact:** Immediately grabs attention
- **Modern:** Large typography is trendy
- **Brand:** Makes "ACE" memorable
- **Hierarchy:** Clear visual priority

### **Why Minimal Shadows?**
- **Modern:** Flat design is current
- **Professional:** Subtle over flashy
- **Performance:** Lighter rendering
- **Consistency:** Easier to maintain
