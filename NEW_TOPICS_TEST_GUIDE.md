# 🔧 Math Game - New Topics Test Guide

## 🎯 **How to See the New Math Topics**

The new topics (Fractions, Percentages, Algebra, Geometry, PEMDAS) are working, but you need to **manually select them** from the dropdown!

---

## 📋 **Step-by-Step Instructions:**

### **1. Start the Math Game:**
```
1. Open index.html
2. Click "Math Practice"
3. Choose any mode (Practice, Timed, Survival, Boss)
4. Game starts with basic arithmetic (this is normal)
```

### **2. Change to New Topics:**
```
1. Look for "Operation Type:" dropdown in the game
2. Click the dropdown menu
3. You'll see these NEW options:
   - ✨ Fractions & Decimals
   - ✨ Percentages & Ratios
   - ✨ Algebra Basics
   - ✨ Geometry
   - ✨ Order of Operations
```

### **3. Select a New Topic:**
```
1. Click on any new topic (e.g., "✨ Fractions & Decimals")
2. The question will IMMEDIATELY change to that topic!
3. You'll see questions like: "Convert 3/4 to decimal"
```

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)

**This is normal behavior!** The new topics are **additional options** you select manually.
